2.1Your first program

Every Kotlin application starts at a function called main. Press ▶ Run to execute it right here in the browser — then try changing the text and running it again.

Three lines, and every one of them matters:

fun
The keyword that declares a function — a named block of code.
main()
The name of the function. main is special: it is the entry point the runtime calls first. The empty () means it takes no parameters.
{ … }
Curly braces delimit the function's body.
println("…")
Calls the standard-library function that prints text followed by a new line. Text in double quotes is a String.
☕
Coming from Java

No class, no public static void, no String[] args, no System.out, no semicolons. Kotlin allows top-level functions — functions that live directly in a file. The compiler wraps them in a class called HelloKt for the JVM behind the scenes.

2.2Statements, printing & comments

A program is a list of statements executed top to bottom. Each statement normally sits on its own line; semicolons are optional (use one only to put two statements on a single line).

Documentation comments (KDoc)

Comments starting with /** are KDoc. IDEs show them when you hover over the function, and tools like Dokka turn them into HTML docs. Use Markdown inside and [name] to link to parameters or other symbols.

2.4Reading user input

Use readln() to read one line from standard input. It returns a String; convert it with functions like toInt().

⚠️
What if the user types “abc”?

"abc".toInt() throws a NumberFormatException and the program crashes. In lesson 06 you'll learn the safe version, toIntOrNull(), which returns null instead. Also note: the browser Playground has no keyboard input, so run input examples in IntelliJ or the terminal.

2.5What happens when you press ▶

Kotlin is a compiled, statically typed language. The compiler checks your entire program for type errors before it runs, then translates it for a target platform:

Kotlin also targets other platforms with the same language:

Kotlin/JVM

Android, servers (Ktor, Spring), desktop. 100% interoperable with Java.

Kotlin/Native

Native binaries for iOS, macOS, Linux, Windows — no JVM.

Kotlin/JS

Compiles to JavaScript for browsers and Node.js.

Kotlin/Wasm

WebAssembly, used by Compose Multiplatform for the web.

🔍
See it yourself

In IntelliJ: Tools → Kotlin → Show Kotlin Bytecode, then click Decompile. You'll see that fun main() became public static final void main() inside public final class HelloKt.

2.7Reading compiler errors

Errors are not failures — they are the compiler helping you. Each message tells you where (file:line:column) and what. Here are the three you'll see most as a beginner:

  • Unresolved reference — a name the compiler doesn't know: a typo, a missing import, or a variable declared later / in another scope.
  • Type mismatch — you gave a value of one type where another was expected. "2025" is a String; 2025 is an Int.
  • Fix errors from the top down: one mistake often causes several follow-up errors.
💡
Let the IDE fix it

Put the caret on red-underlined code and press Alt+Enter (⌥+↩). For unresolved references the IDE offers to import, create or rename the symbol.

2.8Why Kotlin?

Kotlin was created by JetBrains (first stable release 2016). In 2019 Google announced Android development would be Kotlin-first: new Jetpack libraries, documentation and samples are written for Kotlin, and Jetpack Compose is Kotlin-only.

Concise

Data classes, type inference, lambdas and smart casts remove boilerplate — typically far fewer lines than equivalent Java.

Safe

Null safety is built into the type system, eliminating most NullPointerExceptions at compile time.

Interoperable

Call any Java library from Kotlin and vice versa. Migrate a codebase one file at a time.

Modern concurrency

Coroutines make asynchronous code look sequential — no callback hell.
