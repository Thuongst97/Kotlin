Variables, Types & Operators

Programs remember things in variables, and every value in Kotlin has a type. Learn the difference between val and var, the built-in types, string templates and how operators work.

⏱ 45 min🎯 Beginner▶ All examples are runnable

You will be able to

  • Choose between val, var and const val
  • Rely on type inference — and know when to write types
  • Use Int, Long, Double, Boolean, Char and String
  • Build strings with templates and raw strings
  • Convert between types explicitly
  • Apply arithmetic, comparison and logical operators

3.1val vs var

Kotlin has two keywords for declaring variables:

val — value default choice

Read-only: assigned once, can never be reassigned. Like final in Java.

var — variable

Mutable: can be reassigned later, but only with a value of the same type.

💡
Rule of thumb

Always start with val. Switch to var only when the compiler tells you that you need to reassign. Code with fewer moving parts is easier to read, test and use from multiple threads.

🧠
Read-only ≠ immutable

val means the reference can't change. If it points to a mutable object, the object itself can still change: val list = mutableListOf(1) then list.add(2) is allowed. You'll see this again in lesson 07.

3.2Type inference & explicit types

Kotlin is statically typed: every variable has a type fixed at compile time. But you rarely need to write it — the compiler infers it from the value.

Write the type explicitly when it improves readability, when there's no initial value, or when you want a different type than the one inferred (e.g. val ratio: Double = 1 won't compile, but val ratio: Long = 1 will — integer literals adapt to the expected integer type).

3.4Booleans & characters

A Boolean is true or false. A Char is a single 16-bit Unicode character in single quotes.

3.5Strings & string templates

Strings are immutable sequences of characters. The most useful feature is the template: $name inserts a variable, ${expression} inserts any expression.

Raw (multi-line) strings

Triple quotes """ create a raw string: no escape sequences, line breaks kept. Templates still work. Use trimIndent() to remove the common indentation.

3.6Type conversions

Kotlin never converts numbers implicitly — not even from Int to Long. This prevents subtle bugs. Every numeric type has explicit conversion functions.

☕
Coming from Java

Java widens int to long automatically; Kotlin does not. Arithmetic still mixes types sensibly: Int + Long gives a Long, Int * Double gives a Double. There are no primitive vs. boxed types to choose from in source code — the compiler uses JVM primitives (int) whenever possible and boxes (Integer) only when needed, e.g. for nullable types or generics.

3.8Constants & naming conventions

const val declares a compile-time constant: a primitive or String known at compile time, declared at top level or in an object. The compiler inlines its value wherever it's used.

3.9The type hierarchy: Any, Unit, Nothing

Any

The root of every non-nullable type (like Java's Object). Provides equals, hashCode, toString.

Unit

“No meaningful value” — the return type of functions that return nothing useful (Java's void). It has exactly one value, also called Unit.

Nothing

“This never returns” — e.g. a function that always throws. It's a subtype of every type, which is why throw can appear anywhere an expression is expected.

3.10Exercises

Exercise 1 — Temperature converter Easy

Given val celsius = 36.6, print the temperature in Fahrenheit (F = C × 9/5 + 32) and Kelvin (K = C + 273.15), each with one decimal place.

Watch out: 9 / 5 alone is integer division (= 1). It works here because celsius * 9 is evaluated first and is already a Double.

Exercise 2 — Seconds to h:mm:ss Medium

Convert val totalSeconds = 9_754 to the format 2:42:34 using /, % and padStart.

Exercise 3 — Receipt formatter Challenge

Store prices as Long cents: coffee 350, bagel 275, juice 425. Compute subtotal, 8% tax (rounded to the nearest cent) and total, and print a receipt using a raw string. Format cents as dollars with two decimals without using Double.
