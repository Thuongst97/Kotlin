A.8The Kotlin mastery checklist

Can you do each of these without looking anything up? Then you've earned “Kotlin master”.

Language

  • Explain val vs immutability, and == vs ===
  • Model a domain with data, sealed and value classes
  • Write extension functions and higher-order functions with lambdas
  • Pick the right scope function in under 3 seconds
  • Explain variance (in/out) and when to use reified
  • Implement a property delegate and a small type-safe DSL

Concurrency

  • Explain suspension vs blocking
  • Use structured concurrency; never GlobalScope
  • Choose dispatchers and make functions main-safe
  • Handle cancellation and exceptions correctly
  • Build UI state with combine + stateIn
  • Test coroutines with runTest and Flows with Turbine

Android

  • Explain the lifecycle, configuration changes and process death
  • Build screens with stateless, hoisted composables
  • Structure an app in UI / domain / data layers with Hilt
  • Persist with Room + migrations and DataStore
  • Call APIs with Retrofit and handle errors properly
  • Schedule reliable work with WorkManager

Professional

  • Write unit tests with fakes and UI tests with Compose testing
  • Debug crashes from Logcat stack traces
  • Set up CI that builds and tests every push
  • Shrink, sign and publish a release to Google Play
  • Read the official docs and source to answer your own questions
  • Ship something of your own 🚀
